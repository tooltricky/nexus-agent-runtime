# ADR 0004：校准 HTTP 与事件合约并验证真实数据

- 状态：已接受
- 日期：2026-10-23
- 范围：B02；不包含 CI、身份认证或新的 Runtime 状态

## 背景

原 OpenAPI 声明创建 Run 的字段为字符串且禁止未知字段。真实 HTTP 验证表明，Spring Boot
默认忽略未知字段，Jackson 还会把数字/布尔值转换为字符串；仅解析 YAML 无法发现这种偏差。
原事件 Schema 没有限制 payload，无法拒绝缺少退避时间、失败原因等关键字段的事件。

## 决策

保留未知请求字段被忽略的行为，幂等判断仅使用反序列化后的 session_id / input。
关闭请求 String 的数字/布尔值自动转换，使这类错误类型与对象/数组一样返回既有
`400 invalid_request`。这是明确的运行时行为收紧：曾依赖数值/布尔值自动转换的请求需要
改为 JSON 字符串；原合约支持的字符串请求不受影响。缺失、null、空白和幂等键校验沿用既有规则。

OpenAPI 3.1 直接引用 JSON Schema 2020-12 领域事件文件。按 event_type 校验 payload 的
字段、类型、状态转换及重试原因/时间/数值范围；领域和数据库测试继续负责跨字段及事务不变量。
响应约定省略尚无值的 output / lease 字段，不用 JSON null 代替省略。

使用测试范围的校验器从仓库合约文件读取定义，检查真实 HTTP 响应和数据库事件，
并通过缺字段、错类型、非法值反例验证检查确实有效。集成测试只连接显式配置的独立测试库。

响应、事件 envelope / payload 允许新增可选字段，消费者忽略未知字段。破坏性变更需要
新 Schema 标识、明确版本分发及迁移规则，不能改写历史事件；当前无 schema_version，不能
把文档 info.version 当成运行时版本。详细规则见 [合约说明](../../packages/contracts/README.md)。

## 影响

API 不新增资源或状态，数据库迁移不变。新增依赖仅用于测试；镜像构建和测试容器必须读取
仓库内的 contracts 目录。此次测试验证 OpenAPI 响应 Schema，未引入完整文档 lint 或 B03 的 CI。
